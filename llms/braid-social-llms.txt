> Braid Social, Inc. is a venture-backed startup (seed $6.8M, August 2023, led by
> Andreessen Horowitz with Initialized Capital, founded by Matthew Cahill and Chris
> Piro). It launched as a creator-economy direct-to-fan platform on braid.ai and
> braid.social, and now ships "Braid Teams" at trybraid.io — an AI-powered employee
> engagement copilot that runs inside Slack, automating icebreakers, games, polls,
> events, reminders, leaderboards and engagement reporting for distributed teams.

## Agent-relevant summary

- **There is no public Braid API.** No developer portal, no API reference, no OpenAPI,

## Pricing (seat-based SaaS, not API plans)

- **Free** — $0/month. Library of 3 games, standard insights, basic leaderboards.
- **Premium** — $5/user/month billed annually ($7 billed monthly). New games monthly,
  advanced game customization, deeper insights, slash commands, recurring games and
  reminders, monthly engagement reports, priority support.
- **Enterprise** — contact us, positioned for 1,000+ users. 1:1 onboarding, custom game
  development, admin dashboards, custom roles and permissions, dedicated support channel.

## Integration surface

The only way to use Braid Teams is to install the Slack app into a Slack workspace and
drive it from Slack (slash commands, in-channel activities). There is no programmatic
entry point for an agent, and no credential a third party can obtain.
